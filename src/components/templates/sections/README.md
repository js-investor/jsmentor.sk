# Sekcne sablony (lorem default)

Tieto komponenty su pripravene ako rychle sablony pre novy web:

- `FaqSectionTemplate`
- `RecenzieSectionTemplate`
- `FazySectionTemplate`

Pouzitie:

```tsx
import FaqSectionTemplate from "@/components/templates/sections/FaqSectionTemplate";

<FaqSectionTemplate />
```

Ak chces obsah na mieru pre konkretnu podstranku, skopiruj prislusny `...Section.tsx`
do noveho suboru a uprav len texty/CTA.
